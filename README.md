# Flowboard — канбан-доска

Учебное веб-приложение для управления задачами. Проект предназначен для демонстрации работы с DOM нативными средствами JavaScript без библиотек и фреймворков.


## Возможности

- создание, редактирование и удаление задач;
- распределение задач по трём статусам;
- изменение статуса с помощью Drag and Drop;
- несколько независимых досок;
- чек-листы, теги, поиск, фильтрация и сортировка;
- повторяющиеся задачи, архив и отмена действий;
- импорт и экспорт резервных копий;
- статистика, недельный график и семь тем оформления;
- интерфейс на русском, игбо, английском, узбекском, украинском, иврите и идише;
- горячие клавиши и клавиатурное перемещение карточек;
- сохранение данных в `localStorage`.

Данные сохраняются локально в браузере, поэтому задачи остаются на доске после перезагрузки страницы.

## Технологии

- HTML5;
- CSS3;
- JavaScript и ES-модули;
- нативный DOM API;
- Drag and Drop API;
- Web Storage API.

## Локальный запуск

Запустите проект через локальный сервер, например:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Автотесты

Проект использует встроенный тестовый раннер Node.js, поэтому установка зависимостей не требуется.

```bash
npm test
```

Дополнительные режимы:

```bash
npm run test:watch
npm run test:coverage
npm run test:e2e
npm run test:all
```

Unit-тесты проверяют CRUD-операции, доски, сортировку, повторения, фильтры,
состояние, `localStorage` и статистику. Playwright E2E-тесты проходят реальные
сценарии интерфейса: создание и архивацию задач, undo, темы, горячие клавиши,
импорт и экспорт.
