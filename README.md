# Hexly — виртуальный питомец

Учебное веб-приложение о заботе о виртуальном питомце. Проект демонстрирует работу с DOM нативными средствами JavaScript без библиотек и фреймворков.

## Возможности

- управление характеристиками питомца;
- кормление, игры и сон;
- магазин и инвентарь;
- история событий;
- сохранение прогресса в `localStorage`.

> Сейчас в репозитории подготовлены структура, разметка и стили. Игровая логика находится в разработке.

## Технологии

- HTML5;
- CSS3;
- JavaScript и ES-модули;
- нативный DOM API;
- Web Storage API.

## Локальный запуск

ES-модули рекомендуется запускать через локальный сервер. Например, с помощью расширения Live Server для VS Code или команды:

```bash
python3 -m http.server 8000
```

После запуска откройте `http://localhost:8000`.
